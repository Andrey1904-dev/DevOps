# DevOps Academy

Локальный MVP персонального учебного кабинета на Python и SQLite, без сторонних
пакетов, внешних API и облака. Расширяет существующие четыре Skills и девять
определений наставников. Диагностика **подготовлена, но не пройдена**; 30-дневная
программа — **черновик**, а не согласованный персональный курс.

## Открыть кабинет

В терминале этого каталога выполните:

    python3 -B academy.py

Откройте http://127.0.0.1:8765. Требуется уже установленный Python 3.11+ со SQLite.
Если порт занят: `python3 -B academy.py --port 8766`. Другие процессы не останавливаются.
Ctrl+C в терминале сервера завершает только этот сервер. Установка пакетов не нужна.

При первом запуске: 0 попыток, 0 выполненных заданий, диагностика не начата,
программа не утверждена. Просмотр страниц ничего не засчитывает.

1. Просмотрите кабинет и границы безопасных симуляций.
2. Только после собственного решения нажмите «Я решил начать диагностику».
3. Сохраните свой ответ; «пока не знаю» допустимо.
4. Подготовьте запрос наставнику, просмотрите его и вручную передайте в Codex,
   отдельно разрешив необходимый вызов. Веб-приложение AI не вызывает.
5. Перенесите полученную проверку именно этой попытки с обоснованием.
6. После девяти тем обсудите и отредактируйте программу, сохраните черновик.
7. Явно утвердите сохранённый план. Только после этого открывается практика.

Не нужно проходить диагностику или утверждать программу ради проверки приложения.
Технические тесты используют отдельные синтетические данные.

## Что реализовано

Обзор, диагностика, редактируемые 30 слотов программы, 10 стартовых уроков и
текстовых лабораторий, попытки и последовательные подсказки, ручная внешняя
проверка, повторение, журнал активности, заметки, экспорт JSON, ручная
маршрутизация запросов к девяти наставникам. Интерфейс — на русском, тёмная тема,
адаптивные CSS-правила. Визуальная проверка браузером пока не выполнена.

Задания охватывают пути, файлы, чтение, поиск, права, процессы, Bash, Git, сети
и повторение Python. Это модели Linux на бумаге, не исполнение команд на macOS.
Продвинутые темы Docker, CI/CD, мониторинга и DevSecOps пока являются слотами
программы: полноценное содержание требует развития после согласования плана.

Состояния задания: не начато, в процессе, отправлено на проверку, требует
исправления, выполнено. Автосверка пути не завершает задание. Завершение требует
реальной внешней проверки, перенесённой пользователем с подтверждением. Разбор
готового решения не считается выполнением. Навык требует последующей проверки переноса.

## Данные и резервная копия

База — `data/academy.sqlite`, создаётся локально при запуске. Не зашифрована.
Не вводите секреты и персональные данные. Раздел «Данные и запуск» экспортирует
JSON с историей. Импорт JSON пока не реализован. Для полного восстановления
сохраните отдельную копию SQLite при остановленном сервере; не подменяйте живую базу.
Кабинет рассчитан на одного пользователя доверенной локальной машины.
Не открывайте его во внешнюю сеть.

## Проверки

    python3 -B -m unittest discover -s tests -v
    node --check web/app.js
    node tests/test_frontend.cjs

Node нужен только для проверок, не для работы кабинета. Тесты не читают основную
учебную базу и не записывают в неё вымышленные результаты. Проверка рендеринга в
заглушке DOM не заменяет визуальную и интерактивную проверку браузером.

## Структура и документация

- `AGENTS.md` — общие правила, границы разрешений и адаптация Skills.
- `MENTORS.md` — девять логических ролей и механизм их использования.
- `.codex/agents/` — проектные определения ролей без выбора модели.
- `.agents/skills/` — ровно четыре установленных Skill, исходники без изменений.
- `audit/source-manifest.json` — источники, фиксированные commit и контрольные суммы.
- `THIRD_PARTY_LICENSES/` — лицензии upstream-источников.
- `SETUP_REPORT.md` — результаты проверки и оставшиеся ограничения.
- `academy.py`, `content.py`, `web/` — сервер, материалы и интерфейс.
- `tests/` — проверки состояний, HTTP, сохранения и рендеринга.
- `docs/ARCHITECTURE.md` — архитектура, педагогический цикл и границы безопасности.
- `audit/mvp-verification.json` — актуальные технические результаты MVP.
- `audit/mentor-tests-2026-10-23.json` — результаты восьми единичных текстовых тестов.

Следующее решение пользователя — начать реальную диагностику. Она не запускалась
при разработке. Автоматической AI-интеграции, Linux VM и настоящего терминала нет.
